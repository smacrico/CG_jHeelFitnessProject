## 1. **jHeel_plugin_v5.0fbbHRV_DEV.py**

**Purpose:**

**Key Functions:**

- **Database Table Management:**  
  - Creates (and can drop) tables for HRV records and session summaries (`hrv_recordsFBB`, `hrv_sessionsFBB`).
  - Handles schema for a wide range of HRV and physiological variables (e.g., `rmssd`, `sdnn`, `SaO2`, `LF`, `HF`, `Mean HR`, etc.).

- **FIT File Parsing:**  
  - Uses the `fitparse` library to read `.fit` files.
  - Extracts detailed HRV and physiological data from both `record` and `session` messages in each file.
  - Supports batch processing of all `.fit` files in a folder.

- **Data Insertion:**  
  - Inserts extracted data into the appropriate database tables.
  - Handles both per-record (beat-to-beat) and per-session (summary) data.

- **Logging:**  
  - Logs all operations and errors to a timestamped log file for traceability.

- **Integration:**  
  - Calls an external plugin (`fbb_hrv_plugin`) for advanced HRV calculations or additional processing.

**Typical Workflow:**
1. (Optionally) Drop and recreate tables to ensure a clean schema.
2. Parse all `.fit` files in a specified directory.
3. For each file, extract and store detailed HRV and session metrics.
4. Log all operations and errors.

- **Logging:**

**Typical Workflow:**
